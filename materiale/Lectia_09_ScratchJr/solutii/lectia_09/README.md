# Soluții pentru profesor - Lecția 9

Copiii construiesc în aplicație. Aceste proiecte sunt exemple opționale pentru profesor. Fiecare copil testează propria lucrare; nu este necesar un partener.

**Începutul probei:** prima pagină și steag. Între rundele M2/M3/R1/R2 revenim prin mingea de pe final, fără Reset sau steag suplimentar. Ascunderea se execută la revenirea prin Go to Page. Miniaturile paginilor servesc editării.

## Misiunea 1: Insula reacționează

[Proiect ScratchJr](01_Insula_reactioneaza.sjr)

**Ținta:** Ambele reacții se termină și sunt gata pentru încă o încercare.

**Pagina 1 - BeachDay**

- Fluture: atingere → mărime inițială → mărește 4 → așteaptă 10 → mărime inițială.
- Câine: atingere → ascunde → așteaptă 10 → arată.

## Misiunea 2: Ieșirea ascunsă

[Proiect ScratchJr](02_Iesirea_ascunsa.sjr)

**Ținta:** Descoperire, final, întoarcere. Jocul este pregătit pentru încă o rundă.

**Pagina 1 - BeachDay**

- Fluture: atingere → trimite portocaliu.
- Câine: atingere → mărime inițială → mărește 4 → așteaptă 10 → mărime inițială.
- Minge: steag → ascunde.
- Minge: la mesaj portocaliu → arată.
- Minge: atingere → pagina 2.

**Pagina 2 - BeachNight**

- Iepure: steag → mărime inițială → mărește 4 → așteaptă 10 → mărime inițială.
- Minge: atingere → pagina 1.

Câinele poate păstra efectul M1 ales de copil. Mărirea din acest exemplu nu este obligatorie.

Animația iepurelui de pe final este un detaliu opțional; descoperirea, trecerea și întoarcerea sunt țintele necesare.

## Verificare individuală

M1: fiecare reacție de două ori. M2 și M3: două runde complete, cu ascundere la întoarcere. R1: trucul iepurelui nu dezvăluie nimic, apoi lanțul funcționează. R2: o rundă numai prin fluture și una numai prin câine. Salvăm, redeschidem și pregătim cu steagul.
