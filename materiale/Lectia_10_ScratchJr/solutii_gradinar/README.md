# Proiectele Lecției 10 — Robotul grădinar

Șase proiecte native ScratchJr, versiunea v1.2. Fiecare include toate imaginile. Importăm numai starterul pe tabletele copiilor.

| Fișier | Conținut | Apă la final |
|---|---|---|
| [start.sjr](start.sjr) | O scenă, 13 personaje fără cod; indicator la 3 | 3 |
| [m1.sjr](m1.sjr) | Două porții pentru A, apoi retur | 1 |
| [m2.sjr](m2.sjr) | M1 și reumplere la stație | 3 |
| [m3.sjr](m3.sjr) | A, reumplere, B, retur — puzzle greu | 1 |
| [r1.sjr](r1.sjr) | Capacitate 4; A și B fără reumplere | 0 |
| [r2.sjr](r2.sjr) | Porții A, B, A, reumplere, B | 2 |

Rezervele pornesc separat din M3. În R1 se schimbă poziția inițială a Indicatorului și traseul; scala este comună. [Pași și programe](../ghid-profesor.html) · [Import](../README.md) · [Testare](../verificare/Gradinarul_60min.md).
