# Proiectele Lecției 4 - Repetiția pentru spectacol

Referințe opționale pentru profesor. Elevii construiesc direct în ScratchJr, numai cu Theatre, Teen, Mother și Pop, fără fișiere distribuite.

| Etapă | Proiect | Pornire și rezultat |
| --- | --- | --- |
| Scena fără cod | [start.sjr](start.sjr) | Trei personaje, fără programe; construim împreună |
| M1 | [m1.sjr](m1.sjr) | Steag: două bătăi și pauză, de trei ori |
| M2 | [m2.sjr](m2.sjr) | Steag: A2, apoi B3 |
| M3 - dificil | [m3.sjr](m3.sjr) | Atinge dirijoarea: A2, B3, A2, B3, Gata! |
| Creație - exemplu | [creatie.sjr](creatie.sjr) | Atinge dirijoarea: A3, B2, A3, B2; B are pauze |
| R1 | [r1.sjr](r1.sjr) | Atinge dirijoarea: același motiv cu pauză la ambii artiști |
| R2 | [r2.sjr](r2.sjr) | Atinge dirijoarea: două runde A-B, apoi B-A o dată |

În galeria ScratchJr Desktop Reborn: Open, alegi fișierul, apoi proiectul importat. Așteaptă sfârșitul înainte de reluare. Dacă ai oprit în mijlocul unei sărituri, folosește Reset Characters.
