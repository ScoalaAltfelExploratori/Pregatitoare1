# Pachet opțional pentru ScratchJr Desktop 1.3.2

Acest folder este numai pentru profesor. Copiii folosesc aplicația oficială de tabletă și creează proiecte noi. Pentru testarea pe PC, [varianta browser](https://richiesamlie.github.io/ScratchJr-Desktop-Reborn/play/) importă direct fișierele SJR și este mai simplă.

Vechiul [ScratchJr Desktop 1.3.2](https://jfo8000.github.io/ScratchJr-Desktop/) este un port comunitar, neoficial. Versiunea verificată nu avea import individual SJR în meniu; autorul oferă restaurarea bazei de proiecte.

`scratchjr.sqllite.restore` conține cele șapte exemple finale cu iepure, minge și parc. **Restaurarea înlocuiește galeria Desktop**, deci folosește un profil de probă sau păstrează mai întâi o copie a întregului folder `Documents/ScratchJR`, cu aplicația închisă. Nu folosi această operație peste lucrări pe care nu le-ai salvat separat.

1. Închide ScratchJr Desktop și salvează copia folderului său de date.
2. Copiază fișierul furnizat în folderul `ScratchJR` din Documents, păstrând numele exact `scratchjr.sqllite.restore` (cu doi l).
3. Pornește aplicația și folosește File → Restore projects. Verifică galeria înainte să continui.

Documents poate fi redirecționat în OneDrive; folosește folderul Documents al utilizatorului, nu o cale presupusă. Această operație este opțională și nu este necesară pe niciun K10.

Restaurarea și rularea au fost verificate anterior cu o versiune intermediară a lecției. Pachetul final cu iepure a fost validat structural, dar nu restaurat din nou în Desktop. Testele complete ale setului final sunt cele din [browser](../verificare/README.md).
