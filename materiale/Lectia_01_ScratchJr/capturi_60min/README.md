# Arhivă - Programe în lanț

Capturi reale din [ScratchJr Desktop Reborn](https://richiesamlie.github.io/ScratchJr-Desktop-Reborn/play/), realizate pe 17 noiembrie 2026 după importul și rularea exemplelor complete. Blocurile au fost selectate în editor; capturile de program sunt decupate direct din zona de programare. Imaginile nu au fost redesenate sau retușate.

`ghid.json` asociază fiecare etapă cu scena, programele personajelor și explicația scurtă. `verificare.json` păstrează pozițiile observate pentru noul exemplu de creație proprie și reluarea lui fără resetare. Celelalte secvențe sunt descrise în [raportul lecției](../verificare/Programe_in_lant_60min.md).

PDF-ul se regenerează cu `python materiale/render_concise_plans.py`, folosind ReportLab, Pillow și pypdf. `render_snapshot_guide.py` adaugă paginile ilustrate după planul concis. Copia pentru website este `materiale/Plan_lectii_ScratchJr_60min.pdf`.

Numele A, B și C identifică personajele din fiecare captură. Mingea nu are program. În R2, C este iepurașul mic din partea de sus.

Aceste capturi aparțin variantei anterioare. Lecția curentă este [Cursa cu ștafetă](../index.html).
