# Capturi reale - Cursa cu ștafetă

Realizate pe 17 noiembrie 2026 în [ScratchJr Desktop Reborn](https://richiesamlie.github.io/ScratchJr-Desktop-Reborn/play/), după importul și rularea proiectelor native. Capturile provin din scenă și din zona de programare. Blocurile nu sunt redesenate.

`ghid.json` asociază fiecare etapă cu fotografiile și explicațiile sale. Programul lui A, neschimbat din M2, folosește aceeași captură în M3, creație și R2. Acolo sunt prezentate în continuare toate programele necesare, chiar și cele neschimbate.

`verificare.json` păstrează observațiile DOM din timpul rulărilor: poziții și vizibilitate. `rezultate.json` conține verificarea predărilor, a sincronizării, a ocolului și a pozițiilor finale. Scriptul `../verificare/check_stafeta.py` verifică aceste observații, fără să simuleze motorul aplicației.

PDF-ul este construit cu `python materiale/render_concise_plans.py`. Are 13 pagini: plan concis, pregătire și soluțiile ilustrate. [Raportul complet](../verificare/Plan_60min.md).
