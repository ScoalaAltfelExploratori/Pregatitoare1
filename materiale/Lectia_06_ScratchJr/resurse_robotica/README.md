# Resurse originale - Robotul de inspecție

`robot-inspectie.png`: robot mobil cu bară de contact portocalie, fundal transparent. `atelier-robotica.png`: atelier 4:3 cu podea liberă. Ilustrații originale generate pentru curs; prompturile sunt păstrate în [prompturi.json](prompturi.json). Nu reprezintă un model comercial de robot.

Imaginile PNG originale sunt păstrate nemodificate. Generatorul le include în SVG-uri ScratchJr cu imagini încorporate; nu depind de URL-uri externe. Barierele și stația sunt SVG-uri vectoriale create pentru lecție. Directorul `native` păstrează aceste patru resurse.

Importă [starterul](../solutii_inspectie/start.sjr), nu imaginile separat. El include ambele bariere; nu este nevoie să găsești resursele în biblioteca globală. Toate blocurile programelor sunt standard ScratchJr, inclusiv La ciocnire și Pop.

Importul, afișarea, rularea și păstrarea resurselor după redeschidere au fost verificate în browser. [Raport și avertizarea versiunii web](../verificare/Inspectie_60min.md). Importul pe Android fizic rămâne de probat înaintea orei.
