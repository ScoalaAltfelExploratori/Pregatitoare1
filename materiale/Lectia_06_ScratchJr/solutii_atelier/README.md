# Proiectele Lecției 6 - Robotul pregătește atelierul

Toate sunt proiecte native, editabile. Au robotul mare și resursele încorporate. Copiii folosesc starterul; celelalte sunt soluțiile profesorului.

| Etapă | Fișier | Conținut |
| --- | --- | --- |
| start | [start.sjr](start.sjr) | Două scene, toate obiectele fără programe |
| m1 | [m1.sjr](m1.sjr) | Încărcare și întoarcere, o scenă |
| m2 | [m2.sjr](m2.sjr) | Curățarea celor trei resturi, o scenă |
| m3 | [m3.sjr](m3.sjr) | Curățenie, deschidere și intrare, o scenă |
| m4 | [m4.sjr](m4.sjr) | Puzzle greu: întregul flux, două scene |
| creatie | [creatie.sjr](creatie.sjr) | Altă amplasare a resturilor și alt traseu, două scene |
| r1 | [r1.sjr](r1.sjr) | 14 pași de curățenie în loc de 16, două scene |
| r2 | [r2.sjr](r2.sjr) | Oprirea robotului și ușii, două scene |

Import: Open în galeria ScratchJr Desktop Reborn, apoi cardul Pregătim atelierul. Proiectele vechi cu bariere rămân separate. Înainte de probă: Stop, scena dorită, Reset Characters, steag. Misiunea completă începe din scena 1.
