# Proiectele Lecției 6 - Robotul de inspecție

Versiunea **Atelier v2.1** are obiecte mărite și programe recalibrate. Descarcă și importă din nou dacă ai copia anterioară; proiectele deja importate nu se actualizează automat.

Pe tabletele copiilor se importă numai starterul, o dată înainte de oră. Soluțiile sunt referințe editabile pentru profesor. Toate resursele personalizate sunt incluse în fiecare SJR.

| Etapă | Fișier | Rezultat |
| --- | --- | --- |
| start | [start.sjr](start.sjr) | Atelier, robot, stație și două bariere; toate fără cod |
| m1 | [m1.sjr](m1.sjr) | Frânare și retragere la contact |
| m2 | [m2.sjr](m2.sjr) | Retragere și un ocol complet |
| m3 | [m3.sjr](m3.sjr) | Puzzle greu: ocolire, continuare și oprire la stație |
| creatie | [creatie.sjr](creatie.sjr) | Barieră mutată și traversare de 7 pași în loc de 6 |
| r1 | [r1.sjr](r1.sjr) | Aceleași reacții, viteză rapidă |
| r2 | [r2.sjr](r2.sjr) | Două bariere, un singur program de evitare |

Import pe laptop: Open în galeria ScratchJr Desktop Reborn, selectează fișierul, apoi cardul L06 Atelier cu etapa aleasă și sufixul v2.1. Stop, Reset Characters, un steag înaintea fiecărei probe. Starterul nu are cod. Bariera 2 stă deoparte până la R2.
