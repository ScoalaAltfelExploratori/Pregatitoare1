# Resursele fabricii

Resurse noi, mari, incluse în toate cele șapte proiecte SJR. Este necesar un singur import al starterului pe tabletă; imaginile nu se instalează separat.

- [Robot industrial](robot-industrial.png), [șasiu rover](sasiu-rover.png), [fundalul fabricii](fabrica.png): create cu instrumentul integrat de generare de imagini. Originalele PNG sunt păstrate nemodificate.
- [Prompts.md](Prompts.md): instrucțiunile exacte pentru cele trei imagini.
- [Robot SVG](native/robot.svg), [șasiu SVG](native/sasiu.svg), [fabrică SVG](native/fabrica.svg): învelișuri native care încorporează PNG-urile și le încadrează în scenă.
- [Roată](native/roata.svg), [far](native/far.svg), [banc](native/banc.svg): desene vectoriale simple, create pentru lecție.
- [Rover complet](native/rover.svg): același șasiu și aceleași două roți, în aceleași poziții relative. Apare la mesajul verde, când piesele separate se ascund.

Toate programele pot fi schimbate în ScratchJr. Resursele sunt incluse în proiect, nu presupunem că există în biblioteca standard sau că aplicația poate grupa automat personajele. [Generatorul proiectelor](../build_fabrica.py) păstrează dimensiunile, alinierea și identificatorii resurselor.
