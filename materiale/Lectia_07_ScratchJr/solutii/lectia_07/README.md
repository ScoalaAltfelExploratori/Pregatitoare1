# Soluții - Lecția 7 Povestea cu două finaluri

Referințe pentru profesor. Copiii construiesc direct în aplicație. Folosim numai resursele incluse.

Începem pe pagina 1 și atingem personajele pe scenă. Miniaturile din dreapta servesc editării. M2, M3 și rezervele permit revenirea prin minge și repetarea fără Reset.

## Misiunea 1: Portalul

[Proiectul](01_Portalul.sjr). Vedem săritura iepurelui înainte să se schimbe scena.

- Pagina 1, Rabbit: atingere → sari 2 → mergi la pagina 2.
- Pagina 2, Dog: atingere → sari 2.

## Misiunea 2: Dus-întors

[Proiectul](02_Dus_intors.sjr). Înapoi în parc, povestea așteaptă o nouă atingere.

- Pagina 1, Rabbit: atingere → sari 2 → mergi la pagina 2.
- Pagina 2, Dog: atingere → sari 2.
- Pagina 2, Ball: atingere → mergi la pagina 1.

## Misiunea 3 - dificilă: Două finaluri

[Proiectul](03_Doua_finaluri.sjr). Două alegeri, două acțiuni diferite și două drumuri înapoi.

- Pagina 1, Rabbit: atingere → mergi la pagina 2.
- Pagina 1, Dog: atingere → mergi la pagina 3.
- Pagina 2, Dog: atingere → sari 2.
- Pagina 2, Ball: atingere → mergi la pagina 1.
- Pagina 3, Rabbit: atingere → mărește 4 → așteaptă 10 → mărime inițială.
- Pagina 3, Ball: atingere → mergi la pagina 1.

## Rezervă 1 - 6-8 minute: Finalul pornește singur

[Proiectul](04_Rezerva_Finalul_singur.sjr). Finalul face acțiunea fără alt tap și rămâne deschis.

- Pagina 1, Rabbit: atingere → mergi la pagina 2.
- Pagina 1, Dog: atingere → mergi la pagina 3.
- Pagina 2, Dog: steag → sari 2.
- Pagina 2, Ball: atingere → mergi la pagina 1.
- Pagina 3, Rabbit: steag → mărește 4 → așteaptă 10 → mărime inițială.
- Pagina 3, Ball: atingere → mergi la pagina 1.

## Rezervă 2 - 8-10 minute: Trei opriri

[Proiectul](05_Rezerva_Trei_opriri.sjr). 1 săritură → 2 sărituri → transformare. Fără reluare automată.

- Pagina 1, Rabbit: atingere → sari 2 → mergi la pagina 2.
- Pagina 2, Dog: steag → repetă 2 [sari 2] → mergi la pagina 3.
- Pagina 3, Rabbit: steag → mărește 4 → așteaptă 10 → mărime inițială.
- Pagina 3, Ball: atingere → mergi la pagina 1.

Poziționarea, pașii de trecere între misiuni și indiciile sunt în [ghid](../../Ghid_profesor.md). Păstrăm o singură pornire pentru rolul descris; înlocuim programele vechi.
