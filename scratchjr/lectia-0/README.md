# Lecția 0 — Laboratorul de cod

**50 de minute · 6–7 ani · laptop și proiector**

Copiii propun instrucțiuni, prezic rezultatul și vin pe rând la laptop. Scopul: să observe cum schimbarea unui bloc schimbă ce face personajul.

[Deschide atelierul](index.html) · [Ghid pe website](ghid.html) · [Cele 10 lecții](../index.html)

## Pornire

Conectează proiectorul, apasă **⛶** sau **F11** și verifică sunetul.

1. Alege **personajul** și **programul** lui.
2. Trage blocuri în zona albă. Schimbă numerele direct pe blocuri.
3. Întreabă copiii ce se va întâmpla și alege răspunsul din dreapta.
4. Apasă **Rulează codul**. Comparați rezultatul, apoi modificați un bloc.

Pentru **Repetă**, pune acțiunea în interiorul blocului. Pentru **La apăsare**, pornește codul, apoi apasă personajul din scenă.

## Butoanele utile

- **Stop:** oprește programul și sunetele.
- **Reia scena:** readuce personajele la început, păstrând codul.
- **Înapoi:** anulează ultima modificare.
- **Șterge:** elimină blocul selectat. **Golește:** elimină toate blocurile programului selectat.
- **Indiciu:** arată un ajutor pentru activitatea curentă.
- **Cuprins → Pentru profesor:** încarcă un exemplu sau alege altă activitate.

Poți adăuga blocuri și prin apăsare. Semnul **+** alege locul de inserare; săgețile de sub program mută blocul selectat.

**Mai departe** se activează când codul atinge ținta. Codul se păstrează între activități, dar se pierde dacă reîncarci sau închizi pagina.

## Planul întâlnirii

Construiți împreună primele cinci exemple. La activitățile 6–10 poți încărca exemplul și modifica un bloc cu ajutorul copiilor.

| Minute | Activitate | Ce construim și verificăm |
| --- | --- | --- |
| 0–4 | Introducere | Arată scena, blocurile și Rulează. Un copil adaugă primul bloc. |
| 4–8 | 1. Mișcare | De la 3: Dreapta 2 → ajungem la 5. Schimbăm 2 în 4 → ajungem la 7. |
| 8–12 | 2. Repetiție | Repetă 3 [Dreapta 2] → ajungem la 6. |
| 12–16 | 3. Magie | Pune Ascunde la trei mingi → din 7 rămân 4. |
| 16–20 | 4. Mesaje | Fluture: Trimite portocaliu → se mărește cățelul. Albastru → iepurașul. |
| 20–24 | 5. Ritm | Pop → Pop → Așteaptă 10 → Pop. Trei sunete; mutăm pauza și ascultăm. |
| 24–27 | Pauză | Două bătăi din palme, un salt mic, statuie. Schimbăm ordinea. |
| 27–30 | 6. Comori | Iepuraș: Dreapta 4. Mingile se ascund la contact → rămân 6. |
| 30–33 | 7. Pagini | Dreapta 4 → Pagina Plajă. De la 3 ajungem la 7, apoi schimbăm scena. |
| 33–36 | 8. Statui | Telecomandă: Așteaptă 5 → Trimite portocaliu. Din 6 dansatori continuă 2. |
| 36–41 | 9. Descoperiri | La apăsare: fluturele trimite portocaliu, cățelul trimite albastru, mingea deschide Noapte. Jucăm lanțul. |
| 41–48 | 10. Finala | Trimite portocaliu → Așteaptă 10 → Trimite albastru → Așteaptă 5 → Pop. Numărăm: 4 + 3 − 2 = 5 animale. |
| 48–50 | Încheiere | „Ce bloc ai schimba pentru o surpriză nouă?” |

**Rezerve, dacă mai este timp:**

- **Înapoi la zero:** de la 5, Stânga 5 → 0.
- **Până la zece:** de la 6, Dreapta 4 → 10.
